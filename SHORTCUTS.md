# Keyboard Shortcuts

Every shortcut in Notepad. On macOS, ⌘ is Command, ⌥ is Option, ⇧ is Shift and ⌃ is Control.

## Files and tabs

| Action | macOS | Windows / Linux |
|---|---|---|
| New Markdown document | ⌘N | Ctrl+N |
| New file of a chosen type | ⇧⌘N | Ctrl+Shift+N |
| Open file | ⌘O | Ctrl+O |
| Open folder (sidebar) | ⌥⌘O | Ctrl+Alt+O |
| Open repository (sidebar) | ⇧⌘O | Ctrl+Shift+O |
| Save | ⌘S | Ctrl+S |
| Save As (choose the type first) | ⇧⌘S | Ctrl+Shift+S |
| Close tab | ⌘W | Ctrl+W |
| Close tab (mouse) | Middle-click the tab | Middle-click the tab |
| Preview a file from the sidebar (replaced by the next one) | Click | Click |
| Open a file from the sidebar and keep it open | Double-click | Double-click |
| Keep a preview tab open | Double-click the tab | Double-click the tab |
| Next / previous tab | ⌃Tab / ⌃⇧Tab | Ctrl+Tab / Ctrl+Shift+Tab |
| Next / previous tab (also) | ⇧⌘] / ⇧⌘[, ⌥⌘→ / ⌥⌘← | Ctrl+PgDn / Ctrl+PgUp, Ctrl+Shift+] / Ctrl+Shift+[, Ctrl+Alt+→ / Ctrl+Alt+← |
| Go to tab 1–8 / last tab | ⌘1–⌘8 / ⌘9 | Ctrl+1–Ctrl+8 / Ctrl+9 |
| Show / hide the sidebar | ⇧⌘E | Ctrl+Shift+E |
| Quit (unsaved work is kept) | ⌘Q | Ctrl+Q |

## Views

| Action | macOS | Windows / Linux |
|---|---|---|
| Markdown: formatted ⇄ source | ⌘/ | Ctrl+/ |
| HTML: preview ⇄ source | ⌘/ | Ctrl+/ |
| JSON, XML: source ⇄ tree view | ⌘/ | Ctrl+/ |
| Format Document (pretty-print) | ⇧⌥F | Shift+Alt+F |

## SQLite databases

| Action | macOS | Windows / Linux |
|---|---|---|
| Run the SQL (or the selected part) | ⌘↵ | Ctrl+Enter |
| Complete a table or column name | ⌃Space or keep typing | Ctrl+Space or keep typing |
| Create the table (New Table dialog) | ⌘↵ | Ctrl+Enter |

## Macros

| Action | macOS | Windows / Linux |
|---|---|---|
| Start / stop recording a macro | ⇧⌘R | Ctrl+Shift+R |
| Play the last recorded macro | ⇧⌘P | Ctrl+Shift+P |
| Run several times, until the end of the file, or a saved macro | Edit → Macro → Run Multiple Times / Saved Macros… | same |

## Find and replace

| Action | macOS | Windows / Linux |
|---|---|---|
| Find | ⌘F | Ctrl+F |
| Find and replace | ⌥⌘F | Ctrl+H |
| Find next / previous | ⌘G / ⇧⌘G | F3 / Shift+F3 |
| Next / previous match (in the find field) | Enter / ⇧Enter | Enter / Shift+Enter |
| Select all matches (multiple cursors, in the find field) | ⌥Enter | Alt+Enter |
| Use the selection as search text | ⌘E | — |
| Replace / replace all (in the replace field) | Enter / ⌘Enter | Enter / Ctrl+Enter |
| Close the find panel | Esc | Esc |
| Go to line | ⌥⌘G | Ctrl+Alt+G |

## Column (block) selection

| Action | macOS | Windows / Linux |
|---|---|---|
| Select a block with the mouse | ⌥ + drag | Alt + drag |
| Grow the block up / down / left / right | ⇧⌥⌘ + arrow keys | Shift+Alt + arrow keys (also Ctrl+Shift+Alt + arrow keys) |
| Grow the block by a page | ⇧⌥⌘ + PgUp / PgDn | Shift+Alt + PgUp / PgDn |

### CSV and log files

| Action | macOS | Windows / Linux |
|---|---|---|
| Select the whole column at the cursor (also several columns, or only the selected lines) | ⌃Space | Ctrl+Space |
| Select a column with the mouse | ⌥ + double-click a field | Alt + double-click a field |

## Editing (code and source view)

| Action | macOS | Windows / Linux |
|---|---|---|
| Undo / redo | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Y |
| Select all | ⌘A | Ctrl+A |
| Select the next occurrence of the selection | ⌘D | Ctrl+D |
| Select all occurrences of the selection | ⇧⌘L | Ctrl+Shift+L |
| Add a cursor above / below | ⌥⌘↑ / ⌥⌘↓ | Ctrl+Alt+↑ / Ctrl+Alt+↓ |
| Select the line | ⌃L | Alt+L |
| Move the line up / down | ⌥↑ / ⌥↓ | Alt+↑ / Alt+↓ |
| Copy the line up / down | ⇧⌥↑ / ⇧⌥↓ | — (Shift+Alt+arrows select a column) |
| Delete the line | ⇧⌘K | Ctrl+Shift+K |
| Indent / outdent | Tab / ⇧Tab, ⌘] / ⌘[ | Tab / Shift+Tab, Ctrl+] / Ctrl+[ |
| Undo the last selection change | ⌘U | Ctrl+U |

## Formatted Markdown

| Action | macOS | Windows / Linux |
|---|---|---|
| Bold / italic / inline code | ⌘B / ⌘I / ⌘E | Ctrl+B / Ctrl+I / Ctrl+E |
| Block menu (heading, list, table, code block…) | Type `/` | Type `/` |
| Heading, list, quote while typing | `## `, `- `, `1. `, `> ` | `## `, `- `, `1. `, `> ` |
| Formatting toolbar | Select text | Select text |
